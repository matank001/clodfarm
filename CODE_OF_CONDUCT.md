# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work and never about the person, and help newcomers
feel welcome. Harassment of any kind isn't tolerated.

Report unacceptable behaviour privately to the maintainers through
[a private security advisory](https://github.com/matank001/claude-farm/security/advisories/new) (it works for
conduct reports too) or by contacting a maintainer directly. Reports are handled confidentially.
